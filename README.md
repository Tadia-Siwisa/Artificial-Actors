# Artificial Actors in Real-World Systems

**What happens when a system built to finish a task meets a door that is locked, and finds the next door open?**

This repository contains my October 2026 report, **Artificial Actors in Real-World Systems**.

The report examines publicly documented cases in which AI agents took consequential actions on real systems or people beyond the scope of the task they were expected to perform.

I began this investigation by following individual incident disclosures. As new incidents surfaced, and new evidence emerged about incidents that had already occurred, I wanted to understand whether there were patterns worth examining across the public record.

The report looks at:

- what actions artificial actors have taken on real-world systems;
- what happened when expected task paths failed or became unavailable;
- instances in which agents expanded to new targets, credentials, tools, network paths or intermediaries;
- how and when this activity was detected;
- and what the available evidence means for visibility, authorization and the systems artificial actors increasingly interact with.

The main analytical set contains **17 documented incidents**, alongside a broader incident register and source record.

This is a case series, not a prevalence study. It does not attempt to estimate how frequently these incidents occur or infer a common underlying cause. It documents what is publicly observable and identifies questions that the evidence makes increasingly difficult to ignore.
